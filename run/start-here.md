# Start Here

You are already in a terminal, and it is already running Python. There is
nothing to install and nothing to set up. Start typing.

This is the same {{TITLE}} course you can download, running in your own browser
tab. Your code runs on your machine, in this tab, never on a server.

---

## Moving around

    ls                  what is in this folder
    cd weeks            go into a folder
    cd ..               go back up
    pwd                 where am I
    cat <file>          read a file

Everything lives under three folders:

    weeks/              the reading. One folder per week
    work/               your exercises. This is where you write code
    code/               the course itself. You do not need to touch this

---

## Doing your first exercise

Open the course and it will tell you where to start.

    python -m {{PKG}}

Then read week one and open the first exercise.

    cat weeks/week-01/README.md
    edit {{FIRST}}

`edit` opens a plain editor. Write your code, then press
`Cmd+S` (or `Ctrl+S`), or click **save and close**. `Esc` cancels.

Run what you wrote.

    python {{FIRST}}

That is the whole loop. Read, edit, run, repeat.

---

## When a program asks you a question

Some exercises use `input()` to ask you something. When one does, the prompt
at the bottom becomes the program's question. Type your answer and press
Enter, the same as you would anywhere else.

If a program gets stuck, or you write a loop that never ends, press `Ctrl+C`
to stop it. That happens to everyone learning loops. It is not a problem.

---

## Your work is saved

Every time you save a file, it is kept in this browser. Close the tab, come
back tomorrow, and your work is still here.

That only covers this one browser on this one machine. To carry your work
between machines, make a free account.

    signup              make one
    login               sign back in
    whoami              check who you are

That is the only thing an account does here. It remembers where you stopped.
Nothing is required, nothing is charged, and the download never needs one.

---

## Getting the course to keep

    download

The downloadable course is the real thing and it is yours forever. No account,
no internet, no browser. A small number of exercises can only run that way,
because they start other programs and a browser tab has no way to do that. The
terminal will tell you plainly when you hit one.

Everything else works right here.

---

## If something goes wrong

    help                every command, with what it does
    ls work/week-01     check you are where you think you are
    reset               throw away your saved work and start clean

`reset` cannot be undone, so use it only when you want a fresh start.
